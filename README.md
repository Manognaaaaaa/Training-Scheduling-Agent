# Training Optimiser

Mini ERP for a driver training department. Tracks annual training targets vs actuals, detects shortfalls, and uses an agentic LLM planner to suggest and sync schedule changes.

## Stack
- Backend: FastAPI (Python)
- Frontend: React (Vite)
- Database: SQLite (dev), Postgres (deploy)

## Structure
- backend/ : API, simulator, agent, services
- frontend/ : React app
- docs/ : project brief and notes
